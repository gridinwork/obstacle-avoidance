# Программа для объезда препятствий

**Версия 74-RU (Русский интерфейс)**

[![Watch the demo video](https://img.youtube.com/vi/4OooUVU1wcw/0.jpg)](https://www.youtube.com/watch?v=4OooUVU1wcw)

> **Примечание:** Доступны две версии:
> - **74-RU** - Русский интерфейс (текущая версия)
> - **74-EN** - Английский интерфейс (предыдущая версия)

Система автоматического объезда препятствий для гусеничного шасси с двумя моторами, использующая LiDAR для обнаружения препятствий и полетный контроллер Pixhawk для управления движением.

## 🎯 Описание проекта

Программа предназначена для автономного управления гусеничным роботом с двумя моторами, обеспечивая автоматическое обнаружение и объезд препятствий в реальном времени. Система использует трехзонный алгоритм анализа расстояний для принятия решений о маневрировании.

## 🔧 Используемое оборудование

- **LiDAR**: RPLIDAR A1 — лазерный сканер для обнаружения препятствий (360° обзор)
- **Вычислительный модуль**: Raspberry Pi 4 (4GB RAM) — основной компьютер системы
- **Полетный контроллер**: Pixhawk 2, 4 или 8 — управление двигателями и навигация
- **Шасси**: Гусеничное шасси с двумя моторами (дифференциальное управление)
- **Камера** (опционально): Raspberry Pi Camera (CSI) или USB-камера для визуального мониторинга

## 📋 Основные возможности

- ✅ Автоматическое обнаружение препятствий с помощью LiDAR A1
- ✅ Трехзонная система классификации препятствий (красная/желтая/зеленая зоны)
- ✅ Интеллектуальный выбор направления объезда (влево/вправо)
- ✅ Управление через MAVLink протокол (GUIDED режим)
- ✅ Поддержка гусеничного шасси с дифференциальным управлением
- ✅ Опциональная активация камеры для визуального мониторинга
- ✅ Графический интерфейс на PyQt5 с визуализацией данных LiDAR
- ✅ Настройка параметров через удобный интерфейс

## 🧠 Алгоритм работы программы

### 1. Сканирование окружения
- LiDAR A1 непрерывно сканирует пространство вокруг робота (360°)
- Полученные точки обрабатываются и классифицируются по зонам

### 2. Трехзонная классификация препятствий

Программа использует три зоны безопасности:

- **🟢 ЗЕЛЕНАЯ ЗОНА** (2.0–3.0 м): Препятствие далеко
  - Действие: Снижение скорости до 70% от базовой
  - Подготовка к возможному маневру

- **🟡 ЖЕЛТАЯ ЗОНА** (1.0–2.0 м): Препятствие приближается
  - Действие: Поворот на 90° в выбранном направлении (влево/вправо)
  - Скорость ограничена до 25% от базовой
  - Переключение в GUIDED режим для точного управления
  - Движение вперед до выхода из опасной зоны

- **🔴 КРАСНАЯ ЗОНА** (0–1.0 м): Препятствие критически близко
  - Действие: Немедленная остановка
  - Движение назад на 1 метр
  - Ожидание выхода в желтую зону
  - Повторная попытка объезда

### 3. Выбор направления объезда

Алгоритм анализирует количество точек препятствий слева и справа:
- Подсчитывает точки в секторах ±45° от направления движения
- Выбирает сторону с меньшим количеством препятствий
- Учитывает границы зон (cyan boundary-aware selection)

### 4. Управление движением

Для гусеничного шасси с двумя моторами:
- **Движение вперед**: Оба мотора работают синхронно
- **Поворот**: Дифференциальное управление (один мотор быстрее другого)
- **Движение назад**: Реверс обоих моторов
- **Остановка**: Плавная остановка обоих моторов

Команды передаются через MAVLink протокол в режиме GUIDED:
- `move_forward` — движение вперед с заданной скоростью
- `move_backward` — движение назад
- `turn_left` / `turn_right` — поворот на заданный угол
- `stop` — остановка

### 5. Возврат в исходный режим

После успешного объезда препятствия:
- Восстановление исходного режима полета (AUTO, MANUAL и т.д.)
- Возобновление движения по заданному маршруту
- Сброс флагов состояния объезда

### 6. Опциональная камера

При активации камеры:
- Непрерывная запись/трансляция видео
- Отображение в графическом интерфейсе
- Использование для визуального мониторинга и отладки
- Поддержка Raspberry Pi Camera (libcamera) и USB-камер

## 🖥️ Графический интерфейс

Интерфейс на PyQt5 включает:
- **Панель LiDAR**: Визуализация облака точек в реальном времени
- **Панель камеры**: Прямая трансляция с камеры (при активации)
- **Статус подключений**: Индикация состояния LiDAR, Pixhawk, камеры
- **Настройки**: Выбор портов устройств, параметров скорости, углов объезда
- **Управление**: Кнопки подключения, запуска/остановки визуализации

## 📦 Установка и запуск

### Требования

**Оборудование:**
- Raspberry Pi 4 (4GB RAM)
- RPLIDAR A1 (подключен через USB)
- Pixhawk 2/4/8 (подключен через USB/UART)
- Опционально: Raspberry Pi Camera или USB-камера

**Программное обеспечение:**
- Raspberry Pi OS 64-bit
- Python 3.8+

### Установка зависимостей

```bash
sudo apt update
sudo apt install -y python3-pyqt5 python3-opencv python3-serial \
    python3-picamera2 libcamera-dev v4l-utils
python3 -m pip install --upgrade pyserial pymavlink rplidar-roboticia numpy
```

Или используйте автоматический установщик:
```bash
python3 install_lib.py
```

### Настройка прав доступа

Добавьте пользователя в группу `dialout` для доступа к последовательным портам:
```bash
sudo usermod -a -G dialout $USER
```
После этого перезагрузите систему.

### Запуск программы

```bash
python3 main.py
```

## ⚙️ Настройка

### Порты устройств (автоматическое определение)

- **Pixhawk**: `/dev/ttyACM0`, `/dev/ttyACM1`, `/dev/ttyAMA0`
- **LiDAR**: `/dev/ttyUSB0`, `/dev/ttyUSB1`, `/dev/serial/by-id/*`
- **Камера**: Raspberry Pi Camera (libcamera) или `/dev/video0`, `/dev/video1`

### Параметры объезда

Настраиваются через интерфейс:
- Углы сканирования препятствий
- Пороги расстояний для зон
- Скорости движения (вперед, назад, поворот)
- Коэффициенты движения

Все настройки сохраняются в `settings.json`.

## 📝 Примечания

- Программа адаптирована для работы с гусеничным шасси с двумя моторами
